# SkillzStorm — Sprint runbook

## Final status goal (definition of done)

- **AAA New** tab (`/games?view=new`) lists **only** games flagged `isAAA` in `web/src/engine/gameData.ts` (starting with **StormGrid Prix**).
- **Expanded Library** tab (`/games?view=library`) holds the **seed / expanded catalog** (formerly mixed into “new”).
- **StormGrid Prix** ships as a **browser racing** experience: track select, multi-lap race, rivals, finish flow; **10 virtual-world tracks** generated by `npm run stormgrid:gen-tracks` (outputs under `web/src/games/stormGridPrix/data/tracks/`).
- **Cover art** for StormGrid Prix: `web/public/images/covers/storm-grid-prix-cover.svg`.
- **Line-count target** for the StormGrid Prix package: on the order of **~15k lines** (mostly generated track polylines + game code). Verify: `wc -l web/src/games/stormGridPrix/**/*.{ts,tsx}`.
- **Build passes**: from `web/`, `npm run build`.
- **Git**: push to GitHub only when you explicitly ask (this runbook does not imply auto-push).

## Quick reference

| Tab              | URL                     |
|------------------|-------------------------|
| All games        | `/games`                |
| AAA New          | `/games?view=new`       |
| Expanded Library | `/games?view=library`   |

| Task              | Command                          |
|-------------------|-----------------------------------|
| Regenerate tracks | `cd web && npm run stormgrid:gen-tracks` |
| Multiplayer relay | `cd web && npm run stormgrid:relay` (WebSocket on port 3333; set `VITE_STORMGRID_RELAY_URL` for production). **Private** = host starts when 2+ and all ready. **Public** = auto countdown at 6 drivers. |
| AdSense slots | Set `VITE_ADSENSE_SLOT_DEFAULT` (and optional per-slot keys in `AdConfig.ts`) so `data-ad-slot` values match real units in your AdSense account. |
| Production build  | `cd web && npm run build`        |
